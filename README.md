\# TMDB CLI Tool



A command-line tool that uses the TMDB API to display movie information.



\## Features



\- Now playing movies

\- Popular movies

\- Top rated movies

\- Upcoming movies

\- Error handling



\## Run



python tmdb\_app.py --type popular



python tmdb\_app.py --type playing



python tmdb\_app.py --type top



python tmdb\_app.py --type upcoming
